# PodcastSim

A pipeline that turns a directory of podcast MP3s into cloned host voices, then
(eventually) renders scripted episodes in which those voices converse.

## How it works

Audio flows through stages **S0 → S5**. Each stage reads the previous stage's
output per episode and writes a `_DONE.json` manifest, so finished work is
**skipped** on re-run (resumable across session deaths).

| Stage | Does |
|---|---|
| **S0 ingest** | decode to 16 kHz WAV; probe metadata + real bandwidth; segment speech / music / played-media |
| **S1 diarize** | who speaks when (RTTM); overlap regions; chunks long episodes |
| **S2 identify** | embed every speaker, cluster across episodes → the recurring hosts |
| **S3 dataset** | select clean host-only turns, VAD-segment, transcribe **verbatim**, filter |
| **S4 voices** | fine-tune a voice model per host |
| **S5 render** | script + synthesize episodes *(not built)* |

## Models

| Role | Model |
|---|---|
| Segmentation (S0) | AST — `MIT/ast-finetuned-audioset-10-10-0.4593` |
| Diarization (S1) | pyannote.audio 4 — `pyannote/speaker-diarization-community-1` |
| Speaker embeddings (S2) | WeSpeaker ResNet34-LM (pyannote's) |
| VAD (S3) | Silero VAD v6 |
| Verbatim ASR (S3) | CrisperWhisper — keeps the "um"s and false starts |
| Voice cloning (S4) | Chatterbox TTS — full fine-tune of the T3 transformer per host |

More detail in [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) (data flow, the
stage↔module map, the S-number glossary). Run notes: [`docs/RUNBOOK.md`](docs/RUNBOOK.md).

## Quick start

```bash
uv venv --python 3.12 .venv
uv pip install --python .venv/bin/python -e ".[dev]"
.venv/bin/python -m pytest -q      # test suite
.venv/bin/podcastsim --help        # index / run / status / gates / identify
```

## Layout

```
configs/        thresholds (pipeline.yaml), hosts, per-voice synth settings
src/podcastsim/ orchestrator + per-stage implementation (stages/s0..s5)
scripts/        Colab + Kaggle run helpers
samples/trih/   generated voice clips
tests/          unit tests (synthetic fixtures; no committed audio)
```

Source audio, datasets, and model checkpoints live on Google Drive, not in the repo.
